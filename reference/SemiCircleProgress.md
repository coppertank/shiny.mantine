# Mantine SemiCircleProgress

Half-circle progress indicator. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
SemiCircleProgress(...)
```

## Arguments

- ...:

  Props and children. See
  <https://mantine.dev/core/semi-circle-progress/>.
