# Mantine ModalTitle

Title text of a ModalRoot(). Supports `mantineId` for reactive updates
via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ModalTitle(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/modal/>.
