# Mantine Blockquote

Styled quotation block. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Blockquote(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/blockquote/>.
