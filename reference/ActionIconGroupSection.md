# Mantine ActionIconGroupSection

Non-interactive section (e.g. a label) placed between grouped
ActionIcon()s. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ActionIconGroupSection(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/action-icon/>.
