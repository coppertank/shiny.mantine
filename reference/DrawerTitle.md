# Mantine DrawerTitle

Title text of a DrawerRoot(). Supports `mantineId` for reactive updates
via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
DrawerTitle(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/drawer/>.
