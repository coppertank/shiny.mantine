# Mantine TooltipGroup

Shares open/close delay behaviour across a group of Tooltips. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
TooltipGroup(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/tooltip/>.
