# Mantine Mark

Highlighted text (`<mark>` tag). Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Mark(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/mark/>.
