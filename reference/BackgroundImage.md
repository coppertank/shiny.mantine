# Mantine BackgroundImage

Container with a background image. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
BackgroundImage(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/background-image/>.
