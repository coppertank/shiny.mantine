# Mantine FocusTrapInitialFocus

Invisible marker: the first focusable element FocusTrap() should focus,
if not the first one in DOM order. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
FocusTrapInitialFocus(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/focus-trap/>.
