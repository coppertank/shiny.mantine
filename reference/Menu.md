# Mantine Menu family (dropdown on click)

Generic base for dropdown menus. For the ready-to-use "Button with menu"
and "Split button" patterns see
[`ButtonWithMenu()`](https://coppertank.github.io/shiny.mantine/reference/ButtonWithMenu.md)
and
[`SplitButton()`](https://coppertank.github.io/shiny.mantine/reference/SplitButton.md);
use these primitives only if you need a `Menu` with a target other than
a button.

## Usage

``` r
Menu(...)

MenuTarget(...)

MenuDropdown(...)

MenuLabel(...)

MenuDivider(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/menu/>.
