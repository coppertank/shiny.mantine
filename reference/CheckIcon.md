# Mantine CheckIcon

The checkmark icon Checkbox()/CheckboxCard() render when checked.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
CheckIcon(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/checkbox/>.
