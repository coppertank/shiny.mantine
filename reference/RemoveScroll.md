# Mantine RemoveScroll

Prevents the page behind it from scrolling while enabled. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
RemoveScroll(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/floating/>.
