# Mantine Code

Inline or block code-styled text. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Code(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/code/>.
