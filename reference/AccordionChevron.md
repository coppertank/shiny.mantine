# Mantine AccordionChevron

The chevron icon Accordion() renders next to each control. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
AccordionChevron(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/accordion/>.
