# Mantine VisuallyHidden

Visually hides content while keeping it available to screen readers.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
VisuallyHidden(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/visually-hidden/>.
