# Mantine ButtonGroupSection

Non-interactive section (e.g. a label) placed between grouped Button()s.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ButtonGroupSection(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/button/>.
