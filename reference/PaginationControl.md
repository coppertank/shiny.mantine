# Mantine PaginationControl

Generic clickable pagination-styled button, for building entirely custom
page controls inside PaginationRoot(). Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
PaginationControl(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/pagination/>.
