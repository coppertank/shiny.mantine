# Mantine CloseIcon

The "x" icon CloseButton() renders. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
CloseIcon(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/close-button/>.
