# Mantine DrawerCloseButton

Close ("x") button of a DrawerRoot() - already wired to its onClose.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
DrawerCloseButton(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/drawer/>.
