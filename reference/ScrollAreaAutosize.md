# Mantine ScrollAreaAutosize / NativeScrollArea

`ScrollAreaAutosize()` is
[`ScrollArea()`](https://coppertank.github.io/shiny.mantine/reference/ScrollArea.md)
that grows with its content up to `mah` (max height) before scrolling.
`NativeScrollArea()` uses the browser's native scrollbars instead of
Mantine's custom-styled ones.

## Usage

``` r
ScrollAreaAutosize(...)

NativeScrollArea(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/scroll-area/>.
