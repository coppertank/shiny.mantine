# Mantine Skeleton

Animated placeholder for loading content. Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Skeleton(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/skeleton/>.
