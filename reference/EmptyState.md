# Mantine EmptyState

Placeholder shown when there is no content to display. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
EmptyState(...)

EmptyStateActions(...)

EmptyStateDescription(...)

EmptyStateIndicator(...)

EmptyStateTitle(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/empty-state/>.
