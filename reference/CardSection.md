# Mantine Card.Section

A full-bleed section inside a
[`Card()`](https://coppertank.github.io/shiny.mantine/reference/Card.md)
(e.g. an image header that ignores the card's padding) — pass
`withBorder = TRUE`/`inheritPadding = TRUE` as needed.

## Usage

``` r
CardSection(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/card/#card-section>.
