# Mantine Highlight

Text with highlighted parts (`highlight` prop). Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Highlight(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/highlight/>.
