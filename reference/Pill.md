# Mantine Pill

Small rounded tag/chip element. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Pill(...)

PillGroup(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/pill/>.
