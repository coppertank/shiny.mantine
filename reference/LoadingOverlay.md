# Mantine LoadingOverlay

Mantine LoadingOverlay

## Usage

``` r
LoadingOverlay(visible = FALSE, ...)
```

## Arguments

- visible:

  If `TRUE`, shows the loading overlay. Pass `mantineId` among the `...`
  to be able to toggle it from R with
  [`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

- ...:

  Other props (`overlayProps`, `loaderProps`, ...). See
  <https://mantine.dev/core/loading-overlay/>.
