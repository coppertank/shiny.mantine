# Mantine InputLabel

Standalone input label, styled like InputWrapper()'s own label. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
InputLabel(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
