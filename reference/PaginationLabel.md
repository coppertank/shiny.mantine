# Mantine PaginationLabel

The compact "page X of Y" label PaginationRoot() shows in its
`layout = "responsive"` mode. Supports `mantineId` for reactive updates
via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
PaginationLabel(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/pagination/>.
