# Mantine Textarea (Shiny stateful input, multi-line)

Mantine Textarea (Shiny stateful input, multi-line)

## Usage

``` r
Textarea(inputId, label = NULL, value = "", ...)
```

## Arguments

- inputId:

  Id of the Shiny input; `input[[inputId]]` is synced on every
  keystroke.

- label:

  Field label.

- value:

  Initial value.

- ...:

  Other props (`autosize`, `minRows`, `maxRows`, ...). See
  <https://mantine.dev/core/textarea/>.
