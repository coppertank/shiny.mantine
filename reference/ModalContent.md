# Mantine ModalContent

Content box of a ModalRoot() (holds ModalHeader()/ModalBody()). Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ModalContent(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/modal/>.
