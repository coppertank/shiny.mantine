# Mantine InputSuccess

Standalone input success text, styled like the internal success state of
stateful inputs. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
InputSuccess(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
