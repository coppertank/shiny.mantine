# Mantine Menu.Search / Menu.ContextMenu

`MenuSearch()` renders a search field inside a
[`MenuDropdown()`](https://coppertank.github.io/shiny.mantine/reference/Menu.md).
Wrap a target in `MenuContextMenu()` instead of
[`MenuTarget()`](https://coppertank.github.io/shiny.mantine/reference/Menu.md)
to open the menu on right-click instead of left-click.

## Usage

``` r
MenuSearch(...)

MenuContextMenu(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/menu/>.
