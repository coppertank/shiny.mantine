# Mantine Input

Styled input box (border, focus ring, left/right sections) with no
value/onChange management of its own. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Input(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
