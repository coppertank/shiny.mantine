# Mantine Space

Empty horizontal/vertical spacer. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Space(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/space/>.
