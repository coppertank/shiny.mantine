# Mantine Breadcrumbs

Navigation trail (Home \> Section \> Page). Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Breadcrumbs(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/breadcrumbs/>.
