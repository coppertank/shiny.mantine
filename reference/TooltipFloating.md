# Mantine TooltipFloating

Tooltip that follows the cursor instead of anchoring to the target.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
TooltipFloating(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/tooltip/>.
