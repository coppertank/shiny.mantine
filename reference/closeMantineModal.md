# Close an imperatively-opened modal (`@mantine/modals`)

Close an imperatively-opened modal (`@mantine/modals`)

## Usage

``` r
closeMantineModal(session = shiny::getDefaultReactiveDomain(), id)
```

## Arguments

- session:

  Session object passed to the Shiny server function.

- id:

  Id of the modal (the one returned/assigned when it was opened).
