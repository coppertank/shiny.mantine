# Mantine RollingNumber

Animated rolling/odometer-style number display. Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
RollingNumber(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/rolling-number/>.
