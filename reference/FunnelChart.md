# Mantine FunnelChart (funnel/conversion chart)

`data` is a `data.frame` (or list of rows) with columns `name`, `value`,
and optionally `color` — same shape as
[`PieChart()`](https://coppertank.github.io/shiny.mantine/reference/PieChart.md).

## Usage

``` r
FunnelChart(data, ...)
```

## Arguments

- data:

  Chart data (`data.frame` or list of rows).

- ...:

  Other props. See <https://mantine.dev/charts/funnel-chart/>.
