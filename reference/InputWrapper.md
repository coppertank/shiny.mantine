# Mantine InputWrapper

Label/description/error/required-asterisk chrome around arbitrary custom
content. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
InputWrapper(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
