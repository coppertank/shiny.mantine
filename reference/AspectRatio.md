# Mantine AspectRatio

Keeps a fixed width/height ratio for its content. Supports `mantineId`
for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
AspectRatio(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/aspect-ratio/>.
