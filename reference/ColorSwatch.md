# Mantine ColorSwatch

Small color sample. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ColorSwatch(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/color-swatch/>.
