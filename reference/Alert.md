# Mantine Alert

Warning banner with icon/title/color. Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Alert(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/alert/>.
