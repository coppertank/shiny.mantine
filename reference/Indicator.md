# Mantine Indicator

Badge/dot positioned over an element (e.g. unread notifications).
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Indicator(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/indicator/>.
