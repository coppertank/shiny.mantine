# Mantine Spoiler

Truncated content with a "show more" toggle. Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Spoiler(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/spoiler/>.
