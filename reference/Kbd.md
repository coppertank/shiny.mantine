# Mantine Kbd

Keyboard-key-styled text. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Kbd(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/kbd/>.
