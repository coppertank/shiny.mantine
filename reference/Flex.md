# Mantine Flex

Flexbox container with shorthand props (direction, gap, wrap, align,
justify). Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Flex(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/flex/>.
