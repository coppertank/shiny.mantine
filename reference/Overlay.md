# Mantine Overlay

Semi-transparent layer over some content. Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Overlay(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/overlay/>.
