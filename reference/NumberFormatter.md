# Mantine NumberFormatter

Formats a numeric value as display text (thousand separators, decimals,
prefix/suffix). Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
NumberFormatter(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/number-formatter/>.
