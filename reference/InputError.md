# Mantine InputError

Standalone input error text, styled like InputWrapper()'s own error.
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
InputError(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
