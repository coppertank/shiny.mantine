# Mantine InputBase

Like Input(), extended with a few more style-composition options used
internally by other inputs. Supports `mantineId` for reactive updates
via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
InputBase(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/input/>.
