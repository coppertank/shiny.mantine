# Mantine Marquee

Horizontally scrolling ticker of content. Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Marquee(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/marquee/>.
