# Mantine ModalHeader

Header row of a ModalRoot() (usually ModalTitle() + ModalCloseButton()).
Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
ModalHeader(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/modal/>.
