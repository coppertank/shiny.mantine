# Mantine Scroller

Horizontally scrollable container with prev/next arrow controls (e.g.
for a row of chips/thumbnails). Supports `mantineId` for reactive
updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Scroller(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/scroller/>.
