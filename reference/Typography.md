# Mantine Typography

Applies Mantine's prose/typography styling to arbitrary HTML content
(e.g. rendered Markdown). Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Typography(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/typography/>.
