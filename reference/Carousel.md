# Mantine Carousel

Requires `@mantine/carousel` + `embla-carousel-react` (already included
in the package's JS bundle).

## Usage

``` r
Carousel(...)

CarouselSlide(...)
```

## Arguments

- ...:

  Props and children (`CarouselSlide()`) for `Carousel()`; props for
  `CarouselSlide()`. See <https://mantine.dev/x/carousel/>.
