# Mantine DataList

Key/value list (definition-list style). Supports `mantineId` for
reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
DataList(...)

DataListItem(...)

DataListItemLabel(...)

DataListItemValue(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/data-list/>.
