# Mantine DrawerHeader

Header row of a DrawerRoot() (usually DrawerTitle() +
DrawerCloseButton()). Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
DrawerHeader(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/drawer/>.
