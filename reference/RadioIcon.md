# Mantine RadioIcon

The dot icon Radio()/RadioCard() render when checked. Supports
`mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
RadioIcon(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/radio/>.
