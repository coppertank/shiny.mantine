# Mantine Timeline

Vertical sequence of events. Supports `mantineId` for reactive updates
via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
Timeline(...)

TimelineItem(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/timeline/>.
