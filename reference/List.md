# Mantine List

Bulleted/numbered list. Supports `mantineId` for reactive updates via
[`updateMantineProps()`](https://coppertank.github.io/shiny.mantine/reference/updateMantineProps.md).

## Usage

``` r
List(...)

ListItem(...)
```

## Arguments

- ...:

  Props and children. See <https://mantine.dev/core/list/>.
